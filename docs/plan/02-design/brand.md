# Brand

## Name
**Afterspace.** Wordmark in lowercase: `afterspace`. Tagline: "your friends' page, back from the dead."

## Voice
- Lowercase, short, warm, a little spooky. Dry, not cheesy.
- Haunted words only where they help: "step inside" (join), "summon" (catch up), "the grimoire" (facts),
  "the graveyard" (dead plans and pets), "sealed" (letters).
- Never: "boo!", puns on every button, blood, gore.

| what this space knows | the grimoire |
| say what to add | ask the crystal ball |
| 1 here now | 1 haunting now |
| live sync · connected for everyone | everyone's here, live |
| back to the board | back to the page |
| recent memories | memories |
| demo version | this is the demo page |

## Mascots (replace every upstream character and the blue cat)
| Mascot | Role | Look |

Art is ours: generated or drawn for this project, stored in `public/mascots/`, with a short provenance
note in `public/mascots/README.md` (tool used, date).
